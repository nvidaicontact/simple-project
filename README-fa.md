# ⚡ شروع سریع

FreeNET را در چند مرحله ساده اجرا کنید.

## 1. دریافت پروژه

```bash
git clone https://github.com/MHDLabs/FreeNET.git
cd FreeNET
````

## 2. تنظیم متغیرهای محیطی

یک فایل `.env` بسازید:

```env
SUBSCRIPTION_TOKEN=your_secure_token_here
PORT=8080
```

`SUBSCRIPTION_TOKEN` اجباری است و باید توسط کاربر تنظیم شود.

## 3. ساخت و اجرای Docker

```bash
docker build -t freenet .

docker run -d \
  --name freenet \
  --env-file .env \
  -p 8080:8080 \
  freenet
```

تمام شد. FreeNET آماده اجرا است. ✨

# 🎯 FreeNET چیست؟

FreeNET با یک ایده ساده ساخته شد:

**ابزارهای شبکه نباید فقط به دلیل قدرتمند شدن، پیچیده شوند.**

* آسان برای اجرا
* قابل حمل بین پلتفرم‌ها
* سازگار با محیط‌های Docker

بدون قفل شدن به یک سرویس خاص.
بدون لایه‌های اضافی.
فقط زیرساخت شما، به روش شما. 🌍

# 📡 پروتکل‌های پشتیبانی‌شده

## VLESS WebSocket

یک روش انتقال سبک و استاندارد با پشتیبانی گسترده.

## Trojan WebSocket

مسیریابی احراز هویت‌شده با پسورد و هش امن.

## VLESS XHTTP

پشتیبانی از XHTTP در حالت packet-up برای شبکه‌های انعطاف‌پذیرتر و شرایط سخت‌تر.

# 🏗️ ساختار پروژه

FreeNET عمداً ساختاری ساده، تخت و قابل فهم دارد:

```text
FreeNET/
├── main.py                 # اپلیکیشن FastAPI، Routing و سیستم Subscription
├── core.py                 # ابزارهای اصلی، Relay و آمار
├── protocols/
│   ├── vless.py            # هندلر VLESS
│   ├── trojan.py           # هندلر Trojan
│   └── xhttp.py            # هندلر XHTTP
├── Dockerfile              # تنظیمات کانتینر
└── requirements.txt        # وابستگی‌های پایتون
```

# ⚙️ تنظیمات

FreeNET تمام تنظیمات خود را از طریق Environment Variables دریافت می‌کند.

| متغیر                | وضعیت     | توضیحات                            |
| -------------------- | --------- | ---------------------------------- |
| `SUBSCRIPTION_TOKEN` | ✅ اجباری  | توکن دسترسی به مسیر `/sub/{token}` |
| `VLESS_UUID`         | ❌ اختیاری | UUID سفارشی برای VLESS/XHTTP       |
| `TROJAN_PASSWORD`    | ❌ اختیاری | پسورد سفارشی Trojan                |
| `PORT`               | ❌ اختیاری | پورت اجرای سرویس (پیش‌فرض `8080`)  |

اگر `VLESS_UUID` یا `TROJAN_PASSWORD` تنظیم نشده باشند، FreeNET می‌تواند آن‌ها را به‌صورت خودکار تولید کند.

اما توکن Subscription همیشه توسط کاربر کنترل می‌شود و باید به‌صورت دستی تنظیم شود.

# 📋 سیستم Subscription

مسیر:

```text
https://your-domain/sub/YOUR_TOKEN
```

یک Subscription با کدگذاری Base64 ارائه می‌دهد که با موارد زیر سازگار است:

* v2rayNG
* NekoBox
* Shadowrocket
* سایر کلاینت‌های سازگار

محتویات Subscription:

1. کانفیگ‌های فعال اتصال
2. پروفایل پروتکل‌های پشتیبانی‌شده
3. اطلاعات وضعیت سرویس شامل Uptime و آمار مصرف

این سیستم فقط برای توزیع کانفیگ است؛
یک پنل مدیریت کاربر نیست.
