یک درگاه شبکه (Network Gateway) سبک، مستقل و متن‌باز که با تمرکز روی **سادگی، آزادی و قابلیت حمل** ساخته شده است.

# ⚡ شروع سریع

FreeNET را در چند دقیقه اجرا کنید.

## 1. دریافت پروژه

```bash
git clone https://github.com/MHDLabs/FreeNET.git
cd FreeNET
````

## 2. تنظیم متغیرهای محیطی

یک فایل `.env` بسازید:

```env
SUBSCRIPTION_TOKEN=your_secure_token_here
PORT=8080
```

`SUBSCRIPTION_TOKEN` اجباری است و باید توسط کاربر تنظیم شود.

## 3. ساخت و اجرای Docker

```bash
docker build -t freenet .

docker run -d \
  --name freenet \
  --env-file .env \
  -p 8080:8080 \
  freenet
```

تمام شد. FreeNET آماده است. ✨

FreeNET با یک ایده ساده ساخته شد:

هدف:

* آسان برای اجرا
* قابل حمل بین پلتفرم‌ها
* بدون وابستگی به سرویس خاص

بدون قفل شدن به یک ارائه‌دهنده.
بدون لایه‌های اضافی.
فقط زیرساخت شما، به روش شما. 🌍

# 📡 پروتکل‌های پشتیبانی‌شده

## VLESS WebSocket

یک روش انتقال سبک و استاندارد با پشتیبانی گسترده.

## Trojan WebSocket

مسیریابی احراز هویت‌شده با استفاده از پسورد و هش امن.

## VLESS XHTTP

پشتیبانی از XHTTP در حالت packet-up برای شرایط شبکه‌ای سخت‌تر و انعطاف بیشتر.

# 🏗️ ساختار پروژه

ساختار FreeNET عمداً ساده، تخت و قابل فهم نگه داشته شده است:

```text
FreeNET/
├── main.py                 # اپلیکیشن FastAPI، Routing و سیستم Subscription
├── core.py                 # ابزارهای اصلی، Relay و آمار
├── protocols/
│   ├── vless.py            # هندلر VLESS
│   ├── trojan.py           # هندلر Trojan
│   └── xhttp.py            # هندلر XHTTP
├── Dockerfile              # تنظیمات کانتینر
└── requirements.txt        # وابستگی‌های پایتون
```

# ⚙️ تنظیمات

FreeNET تمام تنظیمات خود را از طریق Environment Variables دریافت می‌کند.

| متغیر                | وضعیت     | توضیحات                            |
| -------------------- | --------- | ---------------------------------- |
| `SUBSCRIPTION_TOKEN` | ✅ اجباری  | توکن دسترسی به مسیر `/sub/{token}` |
| `VLESS_UUID`         | ❌ اختیاری | UUID سفارشی برای VLESS/XHTTP       |
| `TROJAN_PASSWORD`    | ❌ اختیاری | پسورد سفارشی Trojan                |
| `PORT`               | ❌ اختیاری | پورت اجرای سرویس (پیش‌فرض `8080`)  |

در صورت تنظیم نکردن `VLESS_UUID` یا `TROJAN_PASSWORD`، FreeNET می‌تواند آن‌ها را به صورت خودکار تولید کند.

اما:

`SUBSCRIPTION_TOKEN` همیشه باید توسط کاربر تعیین شود.

# 📋 سیستم Subscription

مسیر:

```text
https://your-domain/sub/YOUR_TOKEN
```

یک خروجی Base64 شامل کانفیگ‌های اتصال ارائه می‌دهد.

سازگار با:

* v2rayNG
* NekoBox
* Shadowrocket
* سایر کلاینت‌های سازگار

محتویات Subscription:

1. کانفیگ‌های اتصال فعال
2. پروفایل‌های پروتکل‌های پشتیبانی‌شده
3. اطلاعات وضعیت سرویس شامل Uptime و مصرف ترافیک

این سیستم فقط برای توزیع کانفیگ است؛
یک پنل مدیریت کاربر نیست.
